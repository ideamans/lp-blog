# OGP Image Generation — Editorial Infographic / Monochrome (Sepia)

ユーザーが与えた記事の主題に基づき、**横:縦 = 1200:630（≒ 1.905:1、約 16:8.4）の横長JPG画像**を1枚生成してください。アスペクト比は厳守。極端に横長（パノラマ）や 16:9・4:3 など他比率にしないこと。出力寸法は 1200x630 を目指すこと。
本画像は **オーセンティックな新聞紙面に掲載されるインフォグラフィック** です。
銅版画・木版画・ペン&インクのエングレービングのテイストを保ちつつ、構造としては
「タイトル + サブタイトル + 数値ハイライト + 図版（チャート/ダイアグラム） + キャプション」
からなる情報設計を必ず含めてください。
仕様書や指示文に書かれていないテキストは出力しないでください。

## 1. ビジュアルスタイル（イラストの質感）
- 19世紀末〜20世紀初頭の新聞・百科事典・株式相場欄の図版を踏襲。
- 線画ベース。ハッチング・クロスハッチング・点描による陰影。手彫りのエングレービング感。
- トーンは落ち着いた静謐なセピア / モノクロ。
- **「古紙風の装飾は禁止」**:
  - 紙の黄ばみ・しみ・染み・焼け・経年汚れ・破れ・破断・四隅のめくれ・カール・折り跡・テープ跡・しわ・ファイバーノイズ・点々としたスポット・羊皮紙テクスチャ・グランジ・年代感のある紙テクスチャ — これらは一切使用しないこと。
  - 紙地は **均一でフラットなアイボリー一色** で表現する。
- 写真調・3DCG・ネオン・フラットアイコン・絵文字・現代的グラデーションも禁止。

## 2. カラーパレット（厳守 / 3色のみ）
- 紙地（背景全面）: `#f5f1e8` のオフホワイト・アイボリー。**完全にフラット**。テクスチャ・ノイズ・むら・染み・周辺減光（ビネット）は不可。
- インク（線・本文・ハッチング）: `#1a1612` の深いブラウン寄りブラック。
- 差し色（強調用、面積は控えめに）: バーミリオン `oklch(0.55 0.15 30)` ≒ 落ち着いた朱色。
  - 主要数値、矢印先、しきい値マーカー、ごく短い見出しの下線など、目を惹かせたい箇所のみ。
  - 大きな面塗りはしない。

## 3. タイポグラフィ
- セリフ体 / 明朝体のみ:
  - 欧文: EB Garamond / Times / Caslon 系
  - 和文: Noto Serif JP / Hiragino Mincho 系
- サンセリフ・ゴシック・スクリプト・手書き風・装飾書体は禁止。
- 数字は EB Garamond の old-style numerals のテイスト。
- 最小文字サイズ 22px 相当。インフォグラフィックなので可読性最優先。

## 4. インフォグラフィックの構造（必須要素）
以下の要素を全て含めること。エディトリアル挿絵単独にはしない。

1. **大見出し（短い和文 1 行、または英語）** — 記事の核心を表す。
2. **小見出し / デック** — 1〜2 行で文脈補足（任意、入れすぎない）。
3. **数値ハイライト（KPI ブロック）** — 記事から拾った重要な数値を 1〜3 個、
   大きな old-style numerals で配置。各数値に短いラベルを添える。
4. **図版エリア（ダイアグラム or チャート）** — 銅版画タッチで:
   - 折れ線グラフ・棒グラフ・散布図・天秤・メーター・砂時計・歯車などから 1〜2 つ。
   - 軸ラベル、しきい値線、注釈などをセリフ体で添える。
5. **キャプション / 出典風テキスト** — 下部または図版脇に小さく。
6. **罫線・小さなオーナメント** — 新聞紙面風に、見出しと本文を分ける細い罫線可。

レイアウトは 2〜3 ペイン（例: 左 = KPI とテキスト / 右 = 図版）に分かれていてよい。
中央構図 1 枚絵にせず、紙面を構成する **情報レイアウト** として組み立てること。

## 5. 構図のディレクション
- 1200x630 を有効活用。縁端 24〜40px の余白を確保。
- 派手なフレーム・誇張表現（破れ・キラキラ・装飾リボン過多）は禁止。
- **古紙風の演出は一切しない**: 縁の焼け、四隅のめくれ・カール、折り跡、しみ、ノイズ、ビネット、羊皮紙テクスチャ等は不可。
- 背景はフラットなアイボリー (#f5f1e8) のみ。装飾を加えるなら細い罫線・小さな活字オーナメント程度に留める。
- 上品で読みやすく、紙面の一面記事に同居しても違和感のない密度。

## 6. ウォーターマーク（必須）
- 最初に提供される画像は「ideaman's Today」のウォーターマーク。
- 画像の右下に控えめに配置（幅 150〜180px 程度、端から 16〜24px の余白）。
- ウォーターマーク周囲のインクと重ならないよう、ごく薄い紙地のスポットを敷いて視認性を確保。

## 7. 主題の落とし込み
- 記事から具体的な数値・閾値・比率を 1〜3 個抽出し、KPI ブロックで強調する。
- 主題を象徴する 1 図を銅版画タッチで描画し、軸や注釈を整える。
- 装飾より情報。情報より品位。読者にひと目で論点が伝わる新聞インフォグラフィックを目指す。

## 8. 参照画像の活用
- ウォーターマーク以降に提供された画像は記事内の参照グラフ・図版。
- それらの **数値傾向・形状** を読み取り、銅版画タッチで描き直して再現する（写真調にコピーしない）。
- スタイルは本仕様（モノクロ + セピア + 朱色アクセント / セリフ体）を厳守すること。
